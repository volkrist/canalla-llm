## Что именно сделано в §2/§3 (коммит `8f0cef7`)

Разрешённые формы Pod'ов теперь перечислены явно, всё прочее — инцидент:

| Форма | Смысл |
|---|---|
| один `canalla-migrate-*` | Pod измерения |
| ровно пара `canalla-copy-source-<tx>` + `canalla-copy-destination-<tx>`, один и тот же `<tx>` | транзакция копирования |
| всё остальное с `canalla-` | не распознано → **инцидент** |

| Правило | Действие |
|---|---|
| любой Pod старше **900 с** (по `createdAt` провайдера) | terminate |
| возраст не читается | terminate (fail-closed) |
| TTL достигнут любым концом пары | terminate **ОБА** → `reaper-copy-incomplete.json` (`resumable: true`) → STOP (exit 4) |
| два измерения, два source, два destination, разные `<tx>`, пара + измерение, >2 Pod'ов, нераспознанное имя | terminate всех → `reaper-incident.json` → STOP (exit 2) |
| чужие имена Pod'ов | не трогаются никогда |

Тесты reaper'а: **16/16 PASS** (офлайн, без провайдера и без денег).

Дополнительно: старый «полный tail» watcher'а выведен из эксплуатации — без `--measure-only` он
отказывается запускаться (exit 2), чтобы не создать форму Pod'а, которую kill-switch обязан считать
инцидентом. Копирование будет жить в отдельном `finish-secondary-replica.py` под этим контрактом имён.

## Попытка №1 (04:44:16Z → 04:49:30Z) — технически прошла, **данные неполные**

Pod `1lb6t1ywh60l6t` создан в 04:44:16Z, измерен 04:49:27Z, **автоматически завершён** в 04:49:30Z
(314 с). Но манифест оказался дефектным:

| Поле | Что пришло | Причина |
|---|---|---|
| `gguf_path` | `…Q5_K_M.gguf'` (лишняя кавычка) | `set -x` в busybox трассирует `echo` с одинарными кавычками, и провайдер отдаёт трассу в том же потоке |
| `gguf_bytes` | **0** | маркерная строка не распозналась |
| `binaries` | **пусто** | записи приходят как `id: <ts>` + `data: {"line": …}`, а строки `CANALLA_M_BIN` обязаны начинаться с маркера |
| `serve_selftest` | FAIL | **в alpine нет applet `httpd`**, а `wget --user/--password` не поддерживается |

**Вывод: это FAIL по контракту данных** — том покупать нельзя, пока размер неизвестен.

## Исправления (без нового Pod'а, кроме повторного измерения)

1. **Скрипт Pod'а**: вся выдача значений идёт при `set +x`; добавлена единая строка-факт
   `CANALLA_M_GGUF_FACT path=… bytes=… sha256=…`; поиск бинарей углублён (`find -maxdepth 5`, без `-type f`,
   чтобы находить и ссылки); транспорт переведён на `busybox-extras`/`curl` с самопроверкой трёх методов
   аутентификации.
2. **Парсер** `log_lines()` разворачивает обёртку `id:`/`data:`/`msg:`/`log:`; `log_value()` снимает
   одиночные/двойные кавычки; добавлен fallback по FACT-строке.
3. **Сырой лог сохраняется** (`primary-raw-log.txt`) — после завершения Pod'а провайдер отдаёт 404,
   так что это единственный след тома. Это же позволило **пересобрать манифест офлайн**, без трат.

# ПЛАН КОПИИ (следующий платный шаг) И ДВА РЕШЕНИЯ ОТ ОПЕРАТОРА

Порядок, который будет выполнен без дополнительных вопросов после «да»:

   `canalla-copy-destination-<tx>` в US-NE-1 (монтирует новый том), один `<tx>`;
3. передача HTTP с basic-auth, `wget -c` (возобновляемо), только требуемые файлы: GGUF, `start-llm.sh`,
   `check-llm.sh`, `llama.cpp`-бинарь;
4. byte-for-byte: SHA256 GGUF, байты, число файлов, хеши обоих скриптов, идентичность runtime;

   `placements.env` (`RUNPOD_DATACENTERS`, `RUNPOD_REPLICAS`);
6. немедленное завершение обоих Pod'ов, проверка `running pods = 0`;
7. живой тест на **одном** GPU ≤$2/ч в US-NE-1 с новым томом → Ready → одна генерация; затем Tor-тест на
   том же Pod'е; затем немедленное завершение (AI = Disconnected).

**Решение 1.** Источник копии в US-TX-3 стоит **$1.09/ч**: дешевле там нет ничего (CPU — `HTTP 400`,
GPU ≤$1.00 — отсутствует). Лимит копирования по заданию был ≤$1.00/ч → нужно Ваше «да».

**Решение 2.** 20.75 GB могут не влезть в 15-минутный TTL: при ~100 Mbit/s это ~28 мин (**два
возобновляемых окна**, `wget -c`), при ~300 Mbit/s — одно. Подтвердите «до 2 окон» (≈$0.30–0.60 за копию
при $1.09/ч за оба Pod'а) **или** разрешите осознанно поднять копировальный TTL.

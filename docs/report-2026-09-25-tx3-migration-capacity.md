# §9. ПОПРАВКА ПРОШЛОГО ОТЧЁТА — ВЫПОЛНЕНО

Неверный вывод исправлен в `docs/report-2026-09-25-final-regional-failover.md` (и в его копии на
рабочем столе): вариант «перенести вручную через консоль» **не обходит** отсутствие ёмкости в
US-TX-3. Причина простая и проверяемая:

* `NetworkMount.volumeId` — том должен быть **в том же датацентре, что и Pod**, поэтому никакая ручная
  операция не создаёт compute там, где его нет;

  **US-TX-3 в этот список не входит** (проверено по живой документации);
* значит единственный реальный путь — **дождаться ёмкости в US-TX-3**, ровно как и для нас.

**Ранжирование по вашему правилу:** 1) фактическая доступность — у всех четырёх кандидатов `bookable = 1`;
2) число подходящих SKU — у всех 1; 3) сток — у всех LOW; 4) цена — US-NE-1 и EU-NL-1 равны ($1.09);
5) **география как tie-breaker** → **US-NE-1** (20.75 GB передаются внутри США, а не через Атлантику:
меньше вероятность второй платной 15-минутной окон).

Важно: моя автоматическая сортировка при полном равенстве выводит `chosen: EU-NL-1` (алфавит), поэтому
выбор **US-NE-1 зафиксирован здесь явно** как осознанное решение по вашему tie-breaker'у №5, а не как
вывод скрипта.

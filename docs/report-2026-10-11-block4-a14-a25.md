## 2. A14 — the saved idle-stop now reaches the session

`policy_caps` in `apps/backend/app/cloud/demand.py` sent every Compute Preference **except**
`auto_stop_minutes`, so the chat's automatic ensure let the Gateway apply its own default and the
value on screen was not the value that ran. The field is now part of the one policy contract both
paths use; no new field name was introduced (the API already calls it `auto_stop_minutes`).

Tests: the chat carries the saved value; the manual prewarm carries it; missing preferences are an
empty policy (never a fabricated value); every preference the panel shows is sent; and the Gateway
keeps a client value inside the allowed set and reads it back in `GET /compute/status`.

## 3. A25 — a real release gate with artifact verification

`scripts/release-gate.py`: three modes (`developer`, `candidate`, `publish`) + `--self-test`.
Exit `0` PASS · `1` FAIL · `2` INCOMPLETE (a `BLOCKED` step is never a PASS).

* `developer` — Ruff (both), backend/gateway pytest, Vitest, tsc, Prettier, Vite. No artifact, no
  production secret. **Ran green: 9 steps, 0 FAIL, 0 BLOCKED.**
* `candidate` — the above plus Rust, Playwright, sidecar stamp, packaged Gateway URL and the
  **artifact verification**, which is a hard FAIL when: the installer is missing; the name/version

Workflows: `.github/workflows/ci.yml` (developer, no secrets) and
`release-candidate.yml` (`workflow_dispatch`, requires the `release-installer` artifact, installs
no production key). `--self-test` proves the verifier's FAIL cases with a generated key; it is
exercised by `apps/backend/tests/test_release_gate.py`. Docs: `docs/release-gate.md`.

Only the **public** key already committed is used; the private signing key never enters the script,
CI or an untrusted host. No production installer was built or published.

## 4. Frontend PNG test — PASS

Root cause: `.gitignore` kept `apps/desktop/src-tauri/icons/*` out except three files, while
`tauri.linux.conf.json` references `32x32.png`, `64x64.png`, `128x128.png`, `128x128@2x.png`. A
clean checkout therefore had none, and `linux-packaging.test.ts` failed — the Linux `deb` bundler
would also have had no icons. Fix: the real icons are generated from the tracked `source.svg`
(`npx tauri icon`) and **committed**, with the four `.gitignore` exceptions. Full Vitest: **294
passed, 0 failed** (was 293/1).

## 9. A30–A32 — mock acceptance

Verified against the mock Gateway and the frontend contract tests: model loading, queue admission,
long prefill, first-byte wait, deadline expiry, Gateway outage, honest-not-green Connected, and
"Retry never creates a second Pod" (existing `test_cloud_demand.py` / `test_readiness_ttl.py` /
`ai-connection-bounded.test.tsx`). One real gap was fixed: the backend stream read budget was 180 s,
below the product's own staged budgets (120 s queue + 300 s prefill = 420 s), so a legal
large-context request could be cut off and misreported as a dead model. It is now a still-bounded
450 s (`alex_gateway_stream_timeout_seconds`), with a regression test asserting it covers 120+300
and stays under 1800, and the same short connect timeout.

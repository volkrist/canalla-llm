Canalla LLM 1.2.6 — автономный агент: исследование, сборка, проверка и статус в реальном времени.

Что нового:
- Статус задачи в интерфейсе: что делает агент сейчас, когда было последнее действие, какие
  инструменты выполняются, какие источники реально прочитаны, что создано на компьютере, что уже
  проверено и почему возникла остановка.
- Многостраничное веб-исследование: search → fetch → read с дедупликацией, приоритетом
  официальной документации, датой обновления источника и честным разделением «найдено /
  открыто / прочитано / использовано». Мягкий лимит сохраняет checkpoint и продолжает работу в
  разрешённом бюджете; жёсткий лимит останавливает загрузки и честно сообщает, что осталось
  непрочитанным.
- Security assessment для разрешённого scope: OSV advisories, CISA KEV, статический анализ,
  обязательный повторный прогон проверок после исправления.
- Автономная сборка приложения: план → исследование → создание файлов → зависимости → запуск →
  проверка процесса и HTTP → исправление ошибки → повторная проверка. PID сам по себе не считается
  успехом.
- Компьютер и Tor готовы всегда: готовность отделена от денежной политики, Tor подтверждает
  SOCKS5h-цепочку и сохраняет доказательство, pairing переживает перезапуск без повторного
  подтверждения.
- Финальный ответ больше не может быть пустым, обрывком tool-protocol или эхом процесса
  (`pid`, `exit_code`): публикуется отчёт контроллера о реально выполненных действиях.
- Перезапуск окна и потеря Computer host во время задачи: задача паркуется, сохраняет файлы и
  продолжается через штатный Resume без повторных побочных эффектов.

Исправления надёжности:
- `patch_file` без `new_text` — `invalid_arguments`, а не удаление кода.
- Идентификатор устройства не меняется из-за истёкшего session-токена.
- Первая строка потока переживает холодный prefill.

Ограничения (честно):
- T3/T4 live на настоящей Qwen в этом цикле остаются неподтверждёнными, если подходящая GPU
  недоступна у провайдера: без живого прогона релиз не выдаётся за проверенный.
- Authenticode отсутствует; подпись updater — production-ключ 9B328EFF111D1FB2.

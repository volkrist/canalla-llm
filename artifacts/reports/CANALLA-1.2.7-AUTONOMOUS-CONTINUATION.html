C.1. Бесплатная Windows-среда: реальный CI на windows-latest

Вместо новой тяжёлой локальной VM (запрещена заданием и не работает на 8 ГБ RAM) использован существующий workflow CI, который имеет workflow_dispatch и job developer-gate на windows-latest.

  • gh workflow run CI --ref feature/canalla-1.2.7-autonomous-agent — запуск на нашей ветке.
  • Результат: 7/7 job'ов PASS — developer-gate, native-gate, frontend-e2e, tor-runtime, llama-runtime, llama-runtime-image, installer-build (реальная сборка NSIS на чистой Windows-машине).
  • Повторный прогон после исправления uninstall: run 44907058233, 18m01s, success.
  • Финальный прогон на a11eab8: run 44913607831 (запущен в этой сессии).
  • Linux gate (Ubuntu 24.04, нативный Rust + сборка) — success, 7m05s.

D. Исправленные дефекты

  1. Uninstall оставлял каталог программы при работающем Tor. Молчаливое удаление не могло удалить runtime\tor\tor.exe: каталог и живой демон оставались, а запись деинсталляции исчезала. Добавлен NSIS_HOOK_PREUNINSTALL, который останавливает только alex-llm, alex-backend, alex-host-loop и tor, чей образ лежит внутри $INSTDIR, ждёт закрытия дескрипторов, после чего каталог удаляется. Первая версия хука убивала собственный деинсталлятор — это поймано прогоном и исправлено фильтром по именам.
  2. Research не работал на чистой машине. Каждый HTTPS-запрос падал с unable to get local issuer certificate: упакованный backend использовал корневое хранилище хоста. Клиент исследования теперь строит SSL-контекст из запиненного certifi, а opt-in live-тест реально скачивает публичную страницу и проверяет, что DeepResearch записал источник.
  3. Ранее в этой же линии: database_ahead вместо CommandError при откате; UTF-8 в отчёте релизного гейта.

Внешние ограничения, зафиксированные этой сессией:

  1. Новый Windows-workflow в CI добавить нельзя: у токена gh нет scope workflow, а workflow_dispatch регистрирует только workflow, существующие на default-ветке (main). Поэтому чистая установка проверена на хосте с полным снимком/восстановлением, а не в CI.
  2. Чистая Windows VM не завершает unattended-установку на этой машине (VirtualBox + Hyper-V, 8 ГБ RAM) — повторять не стал, как и требовало задание.
  3. LIVE-поиск требует ключа TinyFish; live *fetch* уже доказан.
  4. Публикация не выполнялась.

Расхождения между прежними отчётами и проверенным состоянием

  • Прежний отчёт фиксировал «uninstall не выполнялся» — теперь выполнен и нашёл дефект, который исправлен и перепроверен.
  • Прежний отчёт считал research проверенным только offline — теперь есть живой HTTPS-прогон, и он вскрыл отсутствие CA-бандла в упакованном продукте.
  • Хеш установщика менялся в этой сессии трижды (исправление uninstall, затем CA-бандл); актуален ec47412e…, все промежуточные значения сохранены в логах гейта.
  • docs/release-1.2.7.md и artifacts/SHA256SUMS-1.2.7.txt обновлены под финальный артефакт.

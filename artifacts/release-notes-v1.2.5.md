# Canalla LLM 1.2.5 — Windows x64

Патч-релиз после аудита 27.10.2026.

## Исправлено

- **Стабильность идентификатора устройства.** Клиент больше не удаляет device-credential при
  401 от heartbeat, если это истёкший bearer-токен, а не отказ `device_auth`. Раньше это
  приводило к повторному pairing каждый час и к десяткам активных записей `paired_devices`.
  Осознанный re-pair теперь отзывает заменяемую запись, а не оставляет дубликат.
- **`patch_file` без `new_text`** больше не считается удалением кода: отсутствующий аргумент
  даёт `invalid_arguments`. Явная пустая строка остаётся допустимой.
- **Пустой финальный ответ** модели заменяется сводкой проверенных действий, а не пустым
  сообщением.
- **Холодный prefill:** первая строка потока получает одно ограниченное продление, поэтому
  первый planner-turn после `ready` не обрывается на 20-секундном лимите.

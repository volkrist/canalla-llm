# Central Alex Gateway — standalone runtime dependencies (Python 3.12).
#
# The Gateway is a separate service: it does NOT install the local backend's full dependency
# set (no fastembed, no Playwright, no pypdf, no pwdlib). It reuses only the backend provider
# core as *source* (imported through ALEX_BACKEND_LIB_DIR), which needs httpx + pydantic only.
#
# Ranges track apps/backend/pyproject.toml so the reused provider core stays compatible with
# the version the local backend is tested against.
#
# psycopg[binary] ships manylinux wheels, so the production image needs no compiler and no
# build tools are left behind in the final layer.
# uvicorn[standard] brings uvloop/httptools/watchfiles and python-dotenv, which is what makes
# an optional `.env` file in the working directory work through pydantic-settings.
